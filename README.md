# DRKZ Launcher

Instalador do Assetto Corsa para os servidores da comunidade DRKZ.

**Baixe em https://drkzracing.com/launcher**

Este repositório só guarda as versões publicadas (o instalador e o `latest.json` usado pela
atualização automática do launcher). O código não é publicado aqui.

Problemas: Discord da DRKZ, https://discord.gg/darkpius
